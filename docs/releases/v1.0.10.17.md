## 背景与范围

- 用户要求把项目中的鼠标/触摸板测试单独做成独立工具，不放进 FactoryTestCases 目录。

- 当前测试对象为 Windows Precision Touchpad；保持源模块已确认的设备识别、划格覆盖、左右键计数和 PASS/FAIL 行为。

## 行为说明

- 全屏覆盖主显示器，隐藏鼠标指针，窗口内划格；全部必测格和左右键次数完成后自动 PASS 并退出。
- Esc 或关窗 FAIL；无整体超时；找不到 Precision Touchpad 或 Raw Input 注册失败 FAIL。
- 配置、日志均在 EXE 所在目录。配置文件缺失时使用 5×10、左键 1、右键 1；文件存在时按源模块成对回退和 Finger 规则解析。
- 退出码 0/1/2/3；日志在内存缓存，结束后一次写 `MouseTest.log`。
