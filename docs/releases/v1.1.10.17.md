# 1.1.10.17 - 新增普通鼠标测试

日期：2026-10-17。基于 1.0.10.17 的 TouchPad 独立工具，在同一工程内新增普通鼠标测试，并增加测试选择配置。

## 目标与设计

- 用户要求在配置中增加普通鼠标测试：鼠标滑动、滚轮滚动、左键单击、双击、右键单击、滚轮点击、鼠标点击滑动。
- 不改变 TouchPad 已确认的 HID 识别、划格、左右键和 PASS/FAIL 行为。
- 两项测试各自独立窗口、独立原始输入注册、独立配置解析、独立判定和清理；共享的只有无业务含义的配置读取、日志和窗口资源管理基础设施。
- 通过 `[TouchPad] Enabled` / `[Mouse] Enabled` 选择测试：可只测触摸板、只测普通鼠标，或两项依次运行。被禁用测试的配置不解析，至少保留一项启用。

## Mouse 测试

- 设备：枚举并记录 `RIM_TYPEMOUSE`；窗口显示并取得焦点后注册 `UsagePage=0x01`、`Usage=0x02`；只处理鼠标 `WM_INPUT`。
- 滑动：累计水平、垂直和总原始移动量，达到 `MoveAxisDistance` / `MoveDistance`。
- 滚轮：向上、向下分别累计，达到 `WheelSteps × 120`。
- 单击：左键按下后松开，按下期间移动不超过 `ClickTolerance`。
- 双击：两次单击松开间隔不超过系统 `GetDoubleClickTime()`，两次按下期间移动均不超过 `ClickTolerance`。
- 右键/中键：对应按钮按下后松开。
- 拖动：左键按下后移动达到 `DragDistance`，再松开；拖动不计为单击。
- 介于 `ClickTolerance` 与 `DragDistance` 的移动不产生单击或拖动结果，日志/界面保留已完成项，操作员重做即可。
- 全部 7 项完成后自动 PASS，结果页停留约 1 秒后退出；Esc/关窗 FAIL；无整体超时。
- 窗口失去激活时清除未释放按键和双击链。

## 界面

- 全屏 D2D 列表：7 个任务卡、实时计数、进度条、已完成数量和 Esc 提示。
- 宽屏使用两列任务卡 + 右侧活动面板（鼠标轨迹、L/R/M 按键、滚轮和拖动计数）；窄屏使用单列。
- 鼠标测试显示系统指针；TouchPad 测试继续隐藏指针。
- 语言支持 zh-CN、en-US、vi-VN；任务名、说明、结果和提示均使用当前语言。

## 验证

- `build-release.ps1 -RunTests` 编译正式 EXE，7 项定向测试全部通过：
  - TouchPad 配置、判定、隐藏窗口生命周期。
  - Mouse 配置默认值/范围/成对约束/禁用项。
  - Mouse 判定：滑动、滚轮、单击、双击、右键、中键、拖动、单击/拖动分界、慢双击、失焦复位、全禁用即完成。
  - Mouse 隐藏窗口：注入完整 7 项 PASS、Esc 单次 FAIL、`WM_CLOSE` FAIL。
  - 测试选择：默认值、仅鼠标、两项禁用、非法 Enabled、语言、禁用节不解析。
- 正式 EXE 在 2560×1440 桌面实际启动鼠标测试：日志识别到 3 个 `RIM_TYPEMOUSE` 设备（包含实际设备路径和按键数），收到首个 `WM_INPUT`，界面实际显示鼠标移动累计；Esc 后退出码 1 并写入完整日志。
- 默认配置（TouchPad=1、Mouse=0）实际启动：找不到 Precision Touchpad 后退出码 1，日志记录 TouchPad 段和设备错误。
- 两项同时启用实际启动：TouchPad 失败后仍继续打开 Mouse 窗口，Mouse 收到 Esc 后退出码 1；日志同时包含 `===== TouchPad =====` 和 `===== Mouse =====` 两段，验证了顺序执行、失败继续和统一汇总。
- 实际窗口截图检查了两列任务卡、实时计数、活动面板、提示区和中文文本；未覆盖英文/越南文实际窗口、所有 DPI、长文本和窄屏实机。
- 尝试用 `mouse_event` 注入完整流程时 Raw Input 未接收注入事件，因此没有取得正式 EXE 的自动化完整 PASS；完整 PASS 仍由隐藏窗口注入测试证明代码路径。
- 未使用真实鼠标完成 7 项物理操作，未验证滚轮格数、双击手感、物理中键、不同鼠标按键数和系统鼠标加速。
