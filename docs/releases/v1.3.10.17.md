# 1.3.10.17 - 鼠标滑动实时提示

日期：2026-10-17。基于 1.2.10.17 的全屏笔迹画布，增加鼠标滑动实时反馈；判定、配置、日志和退出码不变。

## 变化

- 顶部“滑动”小圆点下方常驻一行实时状态：
  - `总 当前值 / MoveDistance`
  - 蓝色进度条
  - `X 当前值 / MoveAxisDistance · Y 当前值 / MoveAxisDistance`
- 移动鼠标时三个数字实时增加，进度条同步增长；达到目标后整行和圆点变为绿色。
- 滑动项禁用时显示“未启用”和空进度条，不显示分轴数字。
- 顶部栏高度从 108/136 DIP 调整为 132/148 DIP，给实时行留出空间；画布、蓝/橙/绿笔迹、拖动路径、小圆点和底部图例保持。
- 窗口保持全屏置顶，避免任务栏遮住进度行或底部图例。
